# 版本变化自动自检

v0.4.164本机候选／UXP0.3.31新增，正式Release仍为v0.4.159；候选尚未发布。该功能已接入真实后台，不依赖Codex、联网查询或额外Adobe工具。

## 使用方式

正常启动后台即可。后台「运行状态 → 版本变化自动自检」展示最近结果；发现异常时在后台现有页面上方提示，不弹窗、不切换页面、不抢焦点。点击「查看自检报告」定位面板；「导出自检报告」下载脱敏JSON；「标为已读」只收起提示，报告和原请求记录仍保留。新的异常会产生新报告并重新提示。

自动观察应用、Windows构建、PS、已安装／已加载UXP的版本，以及插件报告的官方重绘接口能力。首次取得可用状态或版本、能力、异常发生变化，连续稳定约6秒后检查；PS未启动时等待，启动中、菜单展开及交互忙碌时推迟常规检查。已存在的未知结果允许只读取缓存留证，仍保留修改保护。

自检复用原有状态，不增加PS查询、不读取文档内容、不做文档编辑或键鼠注入，不自动安装、重启、清除busy或重发操作。文件整理在后台线程执行；日常状态观察不做每次磁盘写入。自动报告仅保留最近20份；磁盘失败时在后台说明保存失败，不宣称已留证，至少60秒后才再尝试。

## 能发现什么

- PS／UXP版本无法识别、低于支持范围，已加载与已安装版本不一致。
- PS已启动而插件未就绪，插件安装状态异常，预期重绘接口缺失或未报告能力。
- 相较上次正常自检能力发生变化；最近保留的失败任务、未知结果和状态读取异常。
- 新版本出现未知状态格式时保留兼容性线索，不让自检异常中断原有状态推送。

PS24.1+有官方UXP重绘API不等于已验收该宿主的实时预览。PS24.0.1能通过旧脚本重绘，但当前嵌套刷新路径已出现宿主阻塞；候选暂用兼容草稿，旧版实时预览仍待修复。自检会明确说明此限制，不会把“接口存在”或“基础连接通过”当作调色、取消、一次撤销或低配性能通过。

## 报告与隐私

报告保存版本、变化项、能力标志、静态异常分类、可识别的十六进制错误码、已有读取耗时及最近任务阶段；未知请求只保留请求／任务ID。任务最多12项、每项最多8个阶段，总报告上限64KiB。不会包含文档名称／内容、输入文字、凭据、用户配置全文或原始错误全文，不自动上传。

本地路径为应用数据目录的`version-health/reports`；最近报告与已读状态保存在`version-health/state.json`。这不是Windows占用句柄、宿主内部调用栈或所有未来故障的根因分析；需要深入排查时仍使用「统一诊断」，必要的只读系统取样另行执行。

## 本轮验证与限制

373项后台、40项前端、13份插件脚本含51组预览模拟通过。包含版本变化、重复去重、忙碌推迟、能力变化、旧版本限制、未知结果保护、报告脱敏、格式变化、写盘失败、异步不阻塞、保留数量、重启／已读和并发保存测试。10000次缓存观察测量中位约0.011ms、P99约0.014ms，不代表实际按键或屏幕延迟。

本机已切换164实际入口，UXP31正常加载，后台自动生成报告，提示与已读行为通过；C++菜单／热键组件与发行入口核验一致。四主题与英文界面使用只读测试后台验证；实际PS24.0.1页面另有截图，不冒充PS25／26实机。最终修订EXE已切换，实际入口、dist、内置菜单／热键及前端资源一致；EXE启动／重启及实际报告导出、已读跨重启保留通过。PS24.0.1双逻辑处理器／Below Normal和正常资源各6项真实草稿事务通过，完成后资源及主屏前台保持，测试文档已关闭、原用户文档备份已恢复。这些测试不调用预览重绘，不能证明拖动实时画布或实体Caps体验；旧版实时预览仍未完成，不发布。

## Codex界面工具故障的独立结论

`0x80070020`发生于MXC CreateProcessSecurityEnvironment，早于界面插件导入。C／G两个工作目录和普通沙箱命令都复现；PS运行时失败，正常退出菜单服务后仍失败，正常退出PS后恢复。完全卸载本项目UXP再启动PS仍复现，已排除本插件是必要触发条件；测试后插件及管理记录原样恢复。此故障与旧版嵌套刷新卡住不能混为同一根因。

依据[OpenAI沙箱说明](https://learn.chatgpt.com/docs/windows/windows-sandbox)，在保留同等workspace权限和管理配置时，已配置的elevated备用实现可运行。已备份本机Codex配置，仅设置`features.prefer_mxc=false`、保留原有`windows.sandbox="elevated"`，PS运行时新CLI探针通过；未关闭沙箱、未改权限边界或网络策略。当前桌面会话仍在使用已加载的MXC配置，界面工具复测仍失败，需正常重启Codex后核验；这只是临时替代路径，不能宣称已修复Windows内部共享冲突。

本功能不会在其他电脑自动修改Codex配置，也不会把Codex作为Photoshop Menu运行依赖。当前本机24.0.1与办公电脑24.2／Win10 PS2024等故障机的实测范围分别记录。
