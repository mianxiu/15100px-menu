# 文字图层中的列表选项

285／UXP0.3.81开始，列表确认写回时把选项保存在原生文字图层的XMP中。文字仍可由PS编辑，插件重新读取当前正文；元数据记录编号／符号选项，288另记录恢复用的原段落缩进，不保存一份旧正文，不依赖图层名、临时图层ID或本机缓存。

## 使用与范围

在Caps的“文本工具”中选择“列表”，调整缩进、项目符号或编号后确认写回。保存PSD，重新打开并选中该文字层，再打开文本工具，会进入列表页并恢复选项。改名、图层复制及跨文档复制保留选项；副本按自己的最新正文独立编辑。“将结果继续编辑”保留尚未确认的列表选项，最后一并写回；关闭面板仍不保存草稿。

“移除列表”清除本工具标记和列表前缀；288起同时恢复原段落缩进，保留正文层级空白及其他插件元数据。文字和选项在同一历史事务中确认，单独改变选项也可一次撤销；写后核对文字、样式、排版及XMP，失败核对回滚，未知结果不重发。

本页的列表选项保存以原生文字层为底层，PS原生图标和双击行为保持。287另提供[矢量文字对象](TEXT-VECTOR-OBJECTS.md)，将显示和可编辑源保存在同一智能对象图层中。双击打开工具、字体／行距编辑及PS准确预览仍未实现。288候选用PS原生字形测量和段落缩进实现续行悬挂对齐；面板预览仍不是PS准确排版，也不提供PS回车续号。

## 数据与保护

- 仅在主动读取文字工具及写前／写后校验时读取图层XMP，不新增心跳查询。XMP通过既有batchPlay读取；不依赖较新UXP的XMP库，不安装额外依赖。
- 自有命名空间为`https://15100px.menu/ns/list/1.0/`，`options`存储有版本JSON：`schema:1`及`kind/marker/custom_marker/numbering/start`。命名空间是标识，不发网络请求。层级保留在当前正文的缩进中。288／UXP86新增独立的版本1 `layout` 属性，按UTF-16段落范围保存原左缩进／首行缩进，不另存正文；重新生成不累加缩进，移除可恢复。
- Python标准库解析XML，只修改本工具的选项和段落属性，保留其余命名空间。拒绝DTD／实体声明、损坏／冲突／未来版本标记、超过128Ki字符或过深结构；不执行文档携带的代码。原始XMP仅在后端快照和执行端内部使用，不返回原生面板；旧UXP在发布修改前拒绝。
- 不需要为每层建立外部JSON文件。普通正文编辑保留原元数据，重新读取以PS正文为准。复制图层后同一组选项不造成两个副本共享可写正文。

## 路线验证

[Adobe Generator文档](https://github.com/adobe-photoshop/generator-core/wiki/Photoshop-Kevlar-API-Additions-for-Generator)描述了可持久化的图层`generatorSettings`。本机24.0.1中，原始描述符、合法命名空间／JSON及不同保存方式均能在会话中读回，却未随PSD保存，因此没有采用该路线；这不是所有PS版本的结论。图层XMP改用实测可保存的`XMPMetadataAsUTF8`读写，原型及生产事务均分别验收。

## 288普通文字列表

当前单窗口仍从Caps“文本工具”进入。列表符号后使用制表符，由PS在确认事务内测量真实前缀，按层级共用正文列；较短编号向右对齐。真实段落左缩进和负首行缩进控制自动续行，移除时按持久范围恢复原缩进。水平、左对齐的普通文字可用；其他对齐在写前拒绝，不静默改稿。已有文本框尺寸保持，空间不足需由用户先扩大；不提供PS回车自动续号。

PS24.0.1的受限CPU72DPI项目列表及正常300DPI编号列表验证生成、重复应用不累加、移除恢复原缩进；最终共列修正验证真实折行、一次撤销／重做和PSD保存重开。实际288／UXP86菜单会话的焦点交接、生成、重开选项及一次撤销通过，原稿／配置／历史未知和资源保持。仅最后新增的非左对齐拒绝为专项模型验证；原生菜单控制、键鼠决策代码未改。实体键鼠／中文组字、其他PS和故障硬件仍待验，不声明性能提升。完整成功与失败证据见TODO的288记录。

## 289列表符号缺字

字体已安装不代表包含所选字符。用户Myriad Pro样本中的空心圆被自动回退为Adobe Heiti Std，仍显示缺字方框。289候选对非ASCII单符号前缀使用Segoe UI Symbol，Windows GDI以禁止系统字体链接的缺字标志核对真实字形，PS再核对PostScript字体身份；正文、字号与其他样式继续沿原范围映射。指定字体没有正确读回时拒绝，不以另一款“已安装”字体的回退冒充成功。未覆盖的自定义符号明确报错，不安装或下载字体。

受限CPU的用户原稿独立副本和正常300DPI三级Myriad Pro列表，经正式UXP通道核对圆点／空心圆／方块均为SegoeUISymbol，所有拉丁正文仍为MyriadPro-Regular；一次撤销／重做和PSD保存重开通过。真实字体技术字段按PS读回的1校准；87的读回拒绝已确认回滚并保留，未重发。首两份透明合成导出无法辨认字形，未计视觉通过；白色对照副本及正式通道输出已核对。证据.runtime/glyph289-interface-final、glyph289-white-proof及glyph289-font-metadata。
