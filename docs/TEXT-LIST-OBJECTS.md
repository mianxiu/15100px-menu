# 文字图层中的列表选项

285／UXP0.3.81开始，列表确认写回时把选项保存在原生文字图层的XMP中。文字仍可由PS编辑，插件重新读取当前正文；元数据只记录编号／符号选项，不保存一份旧正文，不依赖图层名、临时图层ID或本机缓存。

## 使用与范围

在Caps的“文本工具”中选择“列表”，调整缩进、项目符号或编号后确认写回。保存PSD，重新打开并选中该文字层，再打开文本工具，会进入列表页并恢复选项。改名、图层复制及跨文档复制保留选项；副本按自己的最新正文独立编辑。“将结果继续编辑”保留尚未确认的列表选项，最后一并写回；关闭面板仍不保存草稿。

“移除列表”只清除本工具的标记并移除正文中的列表前缀，保留缩进及其他插件元数据。文字和选项在同一历史事务中确认，单独改变选项也可一次撤销；写后核对文字、样式、排版及XMP，失败核对回滚，未知结果不重发。

本页的列表选项保存以原生文字层为底层，PS原生图标和双击行为保持。287另提供[矢量文字对象](TEXT-VECTOR-OBJECTS.md)，将显示和可编辑源保存在同一智能对象图层中。双击打开工具、字体／行距编辑及PS准确预览仍未实现。PS中的自动折行仍由原段落设置决定；本功能没有把本地列表预览变成PS准确排版，也不提供PS回车续号。

## 数据与保护

- 仅在主动读取文字工具及写前／写后校验时读取图层XMP，不新增心跳查询。XMP通过既有batchPlay读取；不依赖较新UXP的XMP库，不安装额外依赖。
- 自有命名空间为`https://15100px.menu/ns/list/1.0/`，`options`存储有版本JSON：`schema:1`及`kind/marker/custom_marker/numbering/start`。命名空间是标识，不发网络请求。层级保留在当前正文的缩进中。
- Python标准库解析XML，只修改此属性，保留其余命名空间。拒绝DTD／实体声明、损坏／冲突／未来版本标记、超过128Ki字符或过深结构；不执行文档携带的代码。原始XMP仅在后端快照和执行端内部使用，不返回原生面板；旧UXP在发布修改前拒绝。
- 不需要为每层建立外部JSON文件。普通正文编辑保留原元数据，重新读取以PS正文为准。复制图层后同一组选项不造成两个副本共享可写正文。

## 实测与未验

PS24.0.1／UXP6.3.3实际加载81，双逻辑处理器／Below Normal与正常配置分别验证72DPI点文字、300DPI段落文字：预览不写PS，正文＋选项、仅选项及移除标记均单历史／一次撤销，选项修改像素不变；PSD重开、改名、同文档／跨文档复制及原生PS修改后重新读取均通过。最终285冻结程序的生产读取API核验正确目标与选项。原稿分层副本恢复、配置、历史未知及资源保持，测试文档关闭。

688项回归、原生列表选项恢复与输入／焦点／取消／生产SHOWWINDOW矩阵、JS失鲜／回滚／未知保护及冻结启动／重启通过。其他PS、原故障硬件、实体键鼠／PS实屏未验；不声明全版本兼容或性能提升。完整证据在`.runtime/list285-interface-complete`、`list285-frozen-read.json`、`runtime285-verified.json`及`tests285-low.log`。

首两轮脚本的全图层只读序列化失败已完整归档，保留未知而未改成成功；之后改用已验证的textKey定向取样。另一轮产品写回／一次撤销已通过，但诊断报告替换因短暂文件占用停止，原报告保留；最终在独立新文档完成两组，没有重发未知写入。

## 路线验证

[Adobe Generator文档](https://github.com/adobe-photoshop/generator-core/wiki/Photoshop-Kevlar-API-Additions-for-Generator)描述了可持久化的图层`generatorSettings`。本机24.0.1中，原始描述符、合法命名空间／JSON及不同保存方式均能在会话中读回，却未随PSD保存，因此没有采用该路线；这不是所有PS版本的结论。图层XMP改用实测可保存的`XMPMetadataAsUTF8`读写，原型及生产事务均分别验收。
