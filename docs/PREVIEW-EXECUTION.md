# 预览退出与PS原生操作

188／UXP43将宿主执行是否退出和内容结果是否核对完成分开处理。

调整颜色、羽化或密度时仍实时预览；面板内松Caps或固定后再次Caps确认，确认后一次撤销。Esc、右键及中心／空白取消并恢复全部原值，沿用同一个事务。

关闭菜单后，原脚本尚未退出时，只暂时忽略本次已验证图层列表及其子控件的点击，不排队、不补点；小转圈显示原确认或恢复阶段。其他区域和应用不拦截，外部应用不自动弹提示。取得匹配原请求／会话／操作的退出证据，再等原生热键组件确认解除后撤下提示，PS可继续正常选层。

若脚本已退出，但修改或回滚结果尚未核对，后台显示“脚本已退出，PS可正常使用；恢复结果待核对，已暂停插件修改，不自动重发”。原待核对文件、busy及未知任务保留，不将其改成成功；插件继续拒绝新修改，仅读取原请求的最终记录核对。旧请求没有退出证据时仍保持保护。

旧版独立执行路径必须等COM正常返回，并核对返回负载身份；单独出现JSX结果文件不足以证明退出。现代UXP在await的modal函数及finally退出后写明确标记。错误、心跳、超时、关闭菜单都不是退出证据。无需再次向PS发送探测命令，也不借重启解除保护。

本次预览需要加载内置UXP0.3.43；后台安装插件后正常重启PS。旧执行端在发布修改前拒绝并提示更新。
