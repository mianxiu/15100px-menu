# UI 指南

本指南是后续界面工作的默认规范，与 AGENTS.md 一同遵循。用户新的明确要求优先；已有验收布局不得因参考设计或新控件而擅自移动。2026-10-14根据实际菜单、后台与用户截图整理。

## 共同视觉规则

| 项目 | 默认规则与实现 |
| --- | --- |
| 主题 | 原生菜单跟随 PS 的四种明暗主题；使用 theme() 的文字、次级文字、背景、边框、禁用与蓝色强调色。后台也跟随状态心跳里的PS主题，复用同一中性色、蓝色hover／选中及强调色；断线保留最后有效主题，首次缺少状态使用深色，不增加PS查询。禁止组件自行加入独立配色。 |
| 圆角 | 原生使用共享 FrameRounding，4逻辑单位，DPI缩放；后台4px。面板、按钮、卡片、输入、标签及提示一致。 |
| 线条 | 控件弱边框1逻辑单位；不额外加粗描边作为 hover。 |
| 留白 | 原生常规内边距／间距6，紧凑间距4；统一图文起点及垂直居中。后台使用admin.css的共享指标：正文13px／20px，次级12px／18px，标题18px／24px、分区标题14px／20px；按钮／输入32px、内边距5×9px，常规间距6／12px，卡片18px（小窗口16px）。 |
| 字体 | 原生沿用PS字号及预热的字体层级，不逐控件硬编码字体；长尺寸保持一行、数字比单位及小标签突出。后台统一字体栈与正文／标题／说明层级，不逐页面叠加字号覆盖。 |
| 状态 | 正常、hover、选中、禁用共用主题调色板；每种状态下主次文本和图标均可读。hover为主题适配的蓝色，禁用不保留可执行命中。 |

原生共享指标来自 native/FigmaMenuIcons.h 和 native/MenuUiMetrics.h；新增控件引用这些指标，尺寸变化同步命中范围。不要仅设置外层圆角而保留内部默认的大 checkbox、不同高度输入或不一致的填充。

## 布局与操作层级

- 保留中心圆环及带文字的基本操作锚点；无文字图标是外围辅助操作。圆环右侧上排空白／纯色／打组，下排四种调整，下排与圆环等高，两排左对齐、间距4。
- 图层菜单上方左右并排排序；画布不显示排序。颜色标签在圆环下方，文档／图层类型／限制／任务信息在更下方的半透明主题底板内。
- 同用途的并排动作／选项使用一个圆角外框和直线内分隔；外侧圆角、内部不重复圆角。输入字段与独立动作使用相同高度、内边距及紧凑间距。
- 文字基本按钮：高度24、图标12，文字为PS字号95%，左／右内边距9、图文间距6，按真实文本宽度测量。纯图标内容16、按钮及命中24×30，不随文字按钮一起缩小。
- 高的侧边列表首行与圆环等高，向下展开，不垂直居中整个列表。首页预设2列×4行，各列按内容测量宽度；剪贴板独立放上方。没有常驻“最近预设”标题，两行内容与小标签保持原验收布局。
- 不增加默认按键提示；保留实际快捷键、空白／中心取消、右键关闭及重开。忙碌时只展示圆环与反馈，交互请求不排队。

## 形状颜色面板

- 只在图层面板菜单、单选未锁定且支持的形状／填充层上显示；画布、首页、其他面板及输入保护状态隐藏，恢复普通菜单尺寸与键盘行为。形状支持填充与描边并可切换类型；普通纯色／渐变／图案填充层保持PS原生类型、编辑自身内容，其他类型置灰，不显示描边、禁用填充或交换操作。用户2026-10-14明确要求填充层也支持；不得通过删除／重建来转换类型而破坏图层身份、蒙版和一次撤销。
- 面板使用共享主题、4单位圆角、1单位边框、6单位内边距；面板正文复用其他菜单信息面板的预热正文字体（menuFonts[0]），标题、选项、RGB、Hex、下拉和复制反馈同一层级；基本操作保留原PS字号95%层级。行高24、面板内边距6、行间距6、输入文字内边距9；高度按内容收紧，不保留固定大段空白。启用控件为12单位的勾选标记和垂直居中的文字；输入、下拉、复制及交换按钮同高。
- 填充／描边、纯色／渐变／图案以及黑白快捷色采用分段控件。RGB与Hex保持清晰，Hex右侧常驻一键复制；复制反馈保留固定宽度，不让输入框跳动。
- 渐变使用连续颜色条和下方色标，点击色标／条选中节点，拖动色标调整位置；取消节点下拉及百分比拖动框。色标命中与绘制同步，端点可到边缘，不跨越相邻节点，重合节点可轮流选中；选择不改变草稿，拖动只改本地草稿，不自动向PS预览写入。沿用共享主题、24单位条高、12单位色标、4单位紧凑间隙；下方颜色区编辑当前色标。颜色条为分段RGB预览，PS中间点／透明度及原有渐变属性保留。
- 复制当前纯色或选中渐变节点的标准大写 #RRGGBB，只写系统剪贴板；不提交PS、不改草稿或图层、不增加历史记录。图案不伪造单一Hex颜色；无效或未输入完整的Hex不能应用。
- 所有调色均为本地草稿，拖动不写PS。面板内松Caps提交一次；短按固定后再次Caps提交。Esc／右键／中心或空白松键取消。实时身份与样式校验、一次撤销、读回、失败回滚及未知结果不重发保持。

## 提示与图标

动作提示靠近按钮并优先放上方，黑色约85%不透明底、浅色文字、弱边框、4圆角、左右各6内边距。沿用150ms首次停留、60ms同组换文字、90ms窄缝保留、120ms宽度过渡及交叉淡入淡出；不能以旧提示目标执行操作。提示只绘制，不注册命中、不遮挡控件；移出、回中心、禁用、输入保护、动画、关闭或提交即清空。

菜单操作图标优先使用完整Figma原几何；没有对应原件则使用同家族补绘，9×9内容网格、18×24根尺寸、1网格笔画、方形结构及克制小圆端。参考来源与补绘分别记录；构建时生成原生几何，不在唤出时解析设计文件。应用品牌独立采用用户提供的手写PS／MENU图标，来源及可编辑路径在 native/app-icon-design.json。

## 修改与验收

1. 复用共享令牌和组件；调整外观时同步命中、禁用与焦点处理，不改变已验收位置。
2. 检查四种主题、PS字号／DPI、长文本、选中／hover／禁用，确认对齐、留白、边界和提示无遮挡。
3. 回归画布／图层分流、输入保护、外部应用焦点、中心／空白取消、右键重开；颜色复制不修改PS或草稿。
4. 性能分别记录缓存／强制读取、CPU绘制／提交、完整PS事务和实体按键到首帧。拖动／复制不得增加后台请求或固定输入延迟。
5. 构建后切换真实入口，核对服务、原生组件及资源；更新README与TODO。渲染预览、模拟键鼠与实机验收分别记录，未做的实机项不勾选。

## 设备与渲染

- 默认自动：DirectX 11硬件GPU优先，初始化失败回退CPU WARP；后台允许自动／GPU优先／CPU软件兼容。设备不可用时GPU优先也保留软件回退，不让菜单失去可用性。
- 保存选项后仅在菜单隐藏时重建设备，不打断当前交互，不重启PS；后台显示实际GPU／CPU与适配器，不能以请求的模式冒充实际设备。
- CPU准备顶点／绘制指令和GPU实际完成是不同范围；比较同时报告提交与完成查询，后者含队列／驱动／同步等待，不等于按键到屏幕延迟。短期稳定性测试不能替代长期设备兼容结论。

## 后台主题与控件（2026-10-15）

- frontend/src/theme.mjs对齐native/MenuHost.cpp的四主题颜色；新增组件只引用--ui-*令牌，不硬编码独立深蓝底或灰白文字。主题由已有WebSocket状态驱动，只在主题变化时更新，不轮询、不影响PS颜色草稿。
- 导航、页签、任务选择和按钮使用同一hover／active背景。页签为共享4px外框及直线分隔的分段组；独立按钮、输入框和状态标签同圆角／边框。禁用使用主题禁用色，不整体降低透明度；键盘焦点沿用蓝色强调。错误／成功／提醒文字适配明暗主题，保留状态文字，不只靠颜色判断。
- 页面使用单一admin.css，避免多个样式文件重复覆盖字号与padding；六个主页面、页面内滚动、表单草稿及中英文切换保持。后台保留适合桌面管理操作的32px控件，不强制套用原生24逻辑单位的命中尺寸。

## 参考Caps操作栏（2026-10-15）

用户明确要求c／v／f等字母直接作为可点击操作排列在菜单下方；这是可操作按钮，不恢复其他区域默认隐藏的数字／快捷键提示。排列为c、v、f、w、s、Ctrl+w、Ctrl+s，位于颜色标签下方、文档／任务信息上方，不移动环绕基本操作和右侧图标组。共同4单位圆角外框、直线分隔、24行高、文字左右各9留白，复用正文和蓝色hover。hover按原tip规则显示完整动作名；边框分隔线和空白不增加命中，中心松键仍取消。输入保护／锁定／未知目标／首页按条件禁用或隐藏，不显示旧目标动作；调色输入控件编辑时保留正常文字输入。
