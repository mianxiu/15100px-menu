# 完成反馈后自动恢复

154起按用户2026-10-17后续要求：已打开的图层菜单显示成功勾号约450ms后，自动请求新的选择快照。请求身份、PS会话、时效与当前菜单匹配时，恢复完整菜单并保持固定；原环绕布局、锚点和按钮位置保持。

恢复时轮换菜单会话号，清除旧hover／提示／命中和已完成手势；旧会话的点击／松键不能变成新操作。基本能力先恢复，形状颜色信息可随后由同一请求补齐。新鲜结果未到时保持紧凑反馈，不用旧图层缓存启用按钮；超时只重新请求只读快照，不重发原修改。

只恢复仍可见且确认成功的图层菜单。关闭的菜单不会自行弹出，切到Chrome等应用不抢焦点。执行中、失败、未知结果／恢复保护、输入框、未提交颜色草稿、按住Caps／鼠标／修饰键时不自动恢复。画布、首页和通用菜单保留既有行为。不增加Caps按下展开延迟。

后台与原生组件都需154，UXP继续0.3.23，无需为此重启PS。实体验收和其他机器结果在TODO单列，自动回归与真实键鼠验收分别记录。使用说明同步到[Wiki](https://github.com/mianxiu/15100px-menu/wiki/Menu-recovery)。
