# 羽化／密度实时预览

v0.4.157／UXP 0.3.24 起，形状颜色面板底部的羽化与密度在拖动时直接更新 PS 文档。更新主程序后，还需在保存并正常关闭 PS 后安装内置插件，再重新启动加载；旧插件拒绝实时预览协议，不降级成连续独立写入。

## 使用

在 RGB 8／16 位文档中，单选未锁定、支持矢量蒙版的形状图层，把鼠标放在图层面板唤出菜单。羽化范围 0–1000px，密度 0–100%。拖动时可以预览画布变化，面板内松 Caps 确认；短按固定后，再次 Caps 确认。

中心／空白松键、Esc、右键、菜单外取消或切换其他应用会结束预览并恢复原值。确认后一次撤销恢复整次调整；与填充／描边一起修改时仍为同一个历史事务。填充、描边和渐变色标继续是本地草稿，确认前不写入 PS。普通填充层不显示这两项；独立像素蒙版和矢量路径保持。

预览期间底部显示“预览中：羽化／密度”，当前编辑面板保持可用，其余图层操作暂停；先确认或取消再执行其他任务。忙碌时新任务仍拒绝，不积累快捷键或自动排队。

## 执行与恢复

整次预览只发布一个有持久化身份的 UXP 请求，维持一个 Photoshop 历史事务。滑条事件覆盖当前最新值，后台约 80ms 检查一次，UXP 处理完成后读取最新值，不逐项补执行过期位置；确认携带最终完整草稿，不丢失松键前最后数值。

每次预览只写矢量蒙版的实际变化项并读回；确认时核验填充／描边、身份、父组与顺序。仅改蒙版不重写颜色。取消使用历史事务回滚，并核验恢复的原始形状属性和选择；没有恢复确认时保留未知结果保护。

控制文件绑定原请求 ID、PS 会话、凭据及递增序号；预览租约为 4 秒，活跃时续约。后台退出、发布中断或控制文件持续不可读时，插件在下一次可处理控制的时机自动取消回滚。PS 重绘很慢时先读取最新续约，避免把仍存活的会话误当作断线。单次 PS 调用本身仍需等它返回，不强杀或重发。

最终结果先持久化再解除忙碌；会话改变、记录损坏、终态不明或回滚不能确认时，只核对原请求，不重新发布，也不回退 COM 或用重启清除保护。

## 验证范围

原生显示与滑条命中自测、后端并发／末值／终态保护、插件事务回归，与真实 PS 文档测试分别记录。真实测试使用 `tools/verify-mask-preview.py` 的自建文档、UXP 预览读回与终态后的独立 COM 核验；没有合成键鼠。

低配优先模式把 PS 临时限制为两个逻辑处理器、Below Normal，分短批测试，结束恢复资源；覆盖简单形状与 40 层混合文档、1024px 画布、持续拖动、取消、合并改色、长停留、租约失效、1000px／0%边界及一次撤销。`--normal` 为不限制资源的对照。每组开始前检查前台、忙碌和待核对结果；样本构造后仅只读等待 UXP 新鲜心跳，不重发任务。

这模拟 CPU 并发受限，不代表真实低内存、集显或故障 i5／PS24.2 电脑。预览回执耗时不等于实体鼠标到屏幕延迟；实际绘制流畅度、实体 Caps／鼠标与跨 DPI／故障电脑仍需对应环境验收。完整证据见 [TODO](../TODO.md) 和 [Wiki](https://github.com/mianxiu/15100px-menu/wiki/Mask-preview)。
