# 填充／描边与蒙版实时预览

v0.4.159／UXP 0.3.26将颜色与羽化／密度拆成两个独立面板，共用实时预览、取消恢复和一次撤销；修复158带矢量蒙版目标的填充Set不可用。更新主程序后，还需在保存并正常关闭 PS 后安装内置插件，再重新启动加载；旧插件拒绝实时预览协议，不降级成连续独立写入。


## 159：独立面板与填充报错修复

颜色在上方独立面板，羽化／密度在下方独立面板；同宽、间隔6逻辑单位。可在任一面板内松Caps确认，固定后再次Caps确认；面板间空隙松键取消。两面板共同预览、取消恢复全部原值、确认一次撤销，普通填充不显示羽化／密度。

159／UXP26撤回矢量目标上的直接纯色setter，修复填充颜色触发“Set is not currently available”。原请求等用户正常关闭提示后据匹配终态确认失败，没有重复调色或强制清除保护。更新程序后需正常重载内置UXP26。PS可将旧形状隐含的默认描边显式化，仍保持禁用；取消与一次撤销恢复完整原属性。

## 使用

在 RGB 8／16 位文档中，单选未锁定的形状或支持的填充层，把鼠标放在图层面板唤出菜单。拖动选色器、修改有效RGB／Hex、黑白色、渐变节点颜色或位置会预览；形状的类型切换、启用／禁用、描边宽度、交换与图案选择也在同一事务内。仅切换填充／描边、选择色标或复制Hex不写PS，无效或不完整Hex不应用。羽化范围 0–1000px，密度 0–100%。拖动时可以预览画布变化，面板内松 Caps 确认；短按固定后，再次 Caps 确认。

中心／空白松键、Esc、右键、菜单外取消或切换其他应用会结束预览并恢复原值。确认后一次撤销恢复整次调整；与填充／描边一起修改时仍为同一个历史事务。普通纯色／渐变／图案填充层仅编辑自身原生类型，不转换图层、不显示描边或羽化／密度；独立像素蒙版和矢量路径保持。

预览期间底部显示“预览中：填充／描边／蒙版”，当前编辑面板保持可用，其余图层操作暂停；先确认或取消再执行其他任务。忙碌时新任务仍拒绝，不积累快捷键或自动排队。

## 执行与恢复

整次预览只发布一个有持久化身份的 UXP 请求，维持一个 Photoshop 历史事务。颜色与滑条事件在每帧合并，再覆盖当前最新值，后台约 80ms 检查一次，UXP 处理完成后读取最新值，不逐项补执行过期位置；确认携带最终完整草稿，不丢失松键前最后数值。

每次预览只写实际变化通道并读回；带矢量蒙版的颜色统一使用已支持的shapeStyle路径，仅普通填充层使用自身原生属性setter，避免158的Set不可用。颜色读取只针对当前单层的四个属性，不遍历文档树；图案目录沿用缓存。渐变保留角度／缩放／透明度／中间点，描边保留未编辑样式。仅有蒙版变化仍只读写两项DOM属性，不额外读取颜色。确认时核验填充／描边、身份、父组与顺序。仅改蒙版不重写颜色。取消使用历史事务回滚，并核验恢复的原始形状属性和选择；没有恢复确认时保留未知结果保护。

控制文件绑定原请求 ID、PS 会话、凭据及递增序号；预览租约为 4 秒，活跃时续约。后台退出、发布中断或控制文件持续不可读时，插件在下一次可处理控制的时机自动取消回滚。PS 重绘很慢时先读取最新续约，避免把仍存活的会话误当作断线。单次 PS 调用本身仍需等它返回，不强杀或重发。

最终结果先持久化再解除忙碌；会话改变、记录损坏、终态不明或回滚不能确认时，只核对原请求，不重新发布，也不回退 COM 或用重启清除保护。

## 验证范围

原生显示与滑条命中自测、后端并发／末值／终态保护、插件事务回归，与真实 PS 文档测试分别记录。真实测试使用 `tools/verify-paint-preview.py` 与 `tools/verify-mask-preview.py` 的自建文档、UXP 预览读回与终态后的独立 COM 核验；没有合成键鼠。

低配优先模式把 PS 临时限制为两个逻辑处理器、Below Normal，分短批测试，结束恢复资源；覆盖简单形状与 40 层混合文档、1024px 画布、持续拖动、取消、合并改色、长停留、租约失效、1000px／0%边界及一次撤销。`--normal` 为不限制资源的对照。每组开始前检查前台、忙碌和待核对结果；样本构造后仅只读等待 UXP 新鲜心跳，不重发任务。
