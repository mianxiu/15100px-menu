# 后台下拉选择快捷键

155起在“菜单设置 → 快捷键”中，菜单唤出／收起和图层操作都使用两个下拉框：先选左侧组合键，再选右侧按键。支持已有的Ctrl、Alt、Shift、CapsLock、Tab前缀及后台支持的触发键；不必输入快捷键文本。

选好后点击“保存并立即生效”。“放弃修改”恢复上次保存的设置；离开页面不会自动提交。已有自定义绑定保持，组合键显示顺序统一，未编辑的原值不重写。图层操作可选择“未绑定”停用；唤出与收起必须保留。重复绑定会在冲突项下面显示提示，组合未选完时也不能保存；后台继续执行原有最终校验。

单选字母／数字通常需要组合前缀；下拉会禁用不支持的触发选择，添加前缀导致旧按键不再适用时，会提示重新选择，不自动换成其他按键。上下移动仍仅在原生菜单上方按钮操作，没有恢复moveUp／moveDown绑定；Tab默认绑定保持，未接入自动输入法切换。

界面沿用后台PS四主题、字号和控件尺寸，支持中文／英文；窄窗口的快捷键按单列显示。页面仅编辑本地设置草稿，不为下拉添加图层查询或输入钩子等待。菜单布局、忙碌拒绝、目标校验、输入／焦点／取消和未知结果保护均沿用原实现。

本轮源码／隔离验证：333后台、37前端回归；1664种下拉组合与真实后台解析器一致。双逻辑处理器、Below Normal下的无窗口Chrome／独立后台验证了选择、未完成与冲突拦截、保存／重载／放弃、未绑定、四主题和520px窄窗口；真实浏览器截图已检查，主屏前台句柄保持。受限浏览器使用软件渲染，不代表复现PS集显性能；这也不是实体Windows下拉弹出、Caps键鼠或故障机验收。
