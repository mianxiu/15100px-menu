# Caps 柔和投影与性能对照

247／UXP0.3.64已切换本机实际入口。普通Caps的整组按钮、颜色标签、预设卡片、中心环及底部信息增加浅投影；使用8层预设透明度轮廓，2逻辑单位下偏移、8单位扩散，沿用共享圆角及DPI。无每帧模糊、新纹理、额外窗口、PS读取或输入等待；不扩大点击／松键命中。展开编辑面板及搜索／拆分工具窗口未在本轮统一加影。

565回归、投影范围无命中、8组最终原生自测和冻结EXE启动／重启通过；CPU当前主题布局预览已查看，实际247／UXP64及菜单热键组件／dist一致。PS未重启、配置／历史未知及会话保留。GPU离屏局部缺失仍是未结观察，真实PS实屏、实体按键延迟、长闲置和原低配设备尚未验收。

## 测量范围

同一最终247原生EXE，基准专用参数关闭投影（246相同表面绘制路径）→开启投影；不是两份已发布版本的端到端测速。相同电脑／适配器／大字号／浅灰主题／普通图层Caps，先双逻辑处理器与Below Normal，再正常配置；仅限制原生测试进程，未运行PS事务。每个热态场景两侧各200样本，P95取最近秩。GPU为RTX4080，CPU为Microsoft WARP回退，不能代表真实集显／低内存。所有原始样本及其他主题场景保留在.runtime/shadow247-comparison。

构建／提交仅测ImGui帧构建与DX11提交；完成阶段另含DX11 EVENT队列／驱动／同步等待。均不含Present／vsync或实体按键到屏幕。initial-render是已预热进程的场景首帧，两侧各1样本；idle仅250ms，两侧各1样本，不代表冷启动或长闲置。

几何顶点1716→6148，绘制批次1→1；宿主读取0→0、宿主返回量0→0。原生投影开关不写用户配置。内存峰值未测，不以几何量代替内存或实体响应。
