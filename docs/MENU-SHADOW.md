# 248 Win11 风格投影

248／UXP0.3.64已切换实际入口。普通Caps采用宽柔影＋近边接触影，外圈2–16逻辑单位、下偏移4单位，近边1–2单位、下偏移1单位；沿用共享圆角及DPI。透明窗口中各按钮组是绘制表面，因此这是Win11外观近似，并非系统DWM给每组控件生成的默认阴影；保留既有布局，无整窗矩形影。

仍为预设透明度轮廓，无每帧模糊、新纹理、额外窗口、PS读取或输入等待，不扩大命中。展开编辑／搜索／拆分工具窗口未统一加影。566回归、当前主题CPU／GPU预览、冻结启动重启、实际248及dist／菜单／热键资源一致通过；GPU离屏底部既有局部缺失保留，不能据此声称真实PS GPU实屏通过。PS未重启，配置和历史未知保持。

## 247历史对照


247／UXP0.3.64已切换本机实际入口。普通Caps的整组按钮、颜色标签、预设卡片、中心环及底部信息增加浅投影；使用8层预设透明度轮廓，2逻辑单位下偏移、8单位扩散，沿用共享圆角及DPI。无每帧模糊、新纹理、额外窗口、PS读取或输入等待；不扩大点击／松键命中。展开编辑面板及搜索／拆分工具窗口未在本轮统一加影。

565回归、投影范围无命中、8组最终原生自测和冻结EXE启动／重启通过；CPU当前主题布局预览已查看，实际247／UXP64及菜单热键组件／dist一致。PS未重启、配置／历史未知及会话保留。GPU离屏局部缺失仍是未结观察，真实PS实屏、实体按键延迟、长闲置和原低配设备尚未验收。
