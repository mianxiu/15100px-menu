# 后台检测与统一报告

后台“运行状态”用于检查主程序、Photoshop、执行插件、菜单和热键组件是否处于可用状态。304起，“Hook与输入保护”集中显示热键进程、健康上报、配置确认、最近菜单键／F和焦点／输入法保护；无需运行独立采集脚本。

## 查看实时状态

打开后台，在“运行状态”查看“Hook与输入保护”：

- “健康上报持续更新”表示原生组件仍在通信；不能据此判断每个按键都已到达。首次未收到、超过3.5秒未更新、维护失败和进程停止分别显示。
- “配置已生效”表示原生热键组件确认了本轮配置。Hook维护本轮未尝试时不显示为重新挂载成功。
- “最近菜单键／最近 F”区分动作已发出、前台／工作区不符、输入保护未放行及没有匹配动作。动作已发出不等于PS执行成功；仍应查看最近任务和实际结果。
- “焦点保护”未知时保持保护，不以检测为由放开输入。IME待核对记录继续保留，检测不重发请求、不清空恢复记录、不切换输入法布局。
- “最近按键与保护详情”提供最近按键时间、焦点控件类型、工具读取和IME核验信息。F明细只在统一诊断的按键采集期间记录；没有记录不证明Hook失效。

## 采集完整报告

1. 在“统一诊断”选择“综合检测（推荐）”，点击“开始只读诊断”。
2. 5秒内切回PS，点击画布或图层列表，在采集倒计时内分别按菜单唤出键和F。检查文字退出问题时，可进入文字或数值输入，退出后再试。
3. 等待菜单／热键、UXP加载和运行检查结束，点击“导出统一报告”。

报告合并窗口检测、Hook健康与配置、按键判断、各采集阶段的焦点／IME状态，以及既有UXP、任务和读取状态。窗口检测失败时仍保留已取得的缓存证据，并标明未完成项，不把未知变为通过。仅需当前状态时可选择“运行与图层读取”，不启动按键采样。

检测仅读取窗口结构、控件类型、插件加载日志和已有状态，不读取正文或凭据，不向PS提交文档操作，不自动上传。报告包含本机进程号、窗口句柄与版本等诊断信息；提交前可自行检查。

## 限制

本次更新加强检测，不等于修复F故障。PS25.5.1故障机已确认303／UXP0.3.91连接，但F仍无效；需使用该机的新报告继续定位。本机、其他PS版本与远端故障机的验证结果分别记录，不能互相替代。
