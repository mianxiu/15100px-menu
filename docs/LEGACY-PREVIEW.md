# 旧版 Photoshop 独立预览

204／UXP44：修复PS24.0.0被实时预览版本条件排除的问题。该版本已可安装，但旧插件仅对24.0.1及之后的24.0.x报告独立预览能力，后台也有相同门槛，导致颜色／羽化不能实时生效。现将独立预览路径扩展到24.0.0，必须实际加载UXP44并报告对应能力；旧UXP43在24.0.0仍不会被强行启用。23.x仍保持兼容草稿，24.1+仍须实际提供官方重绘API，不在未知结果后改走另一通道。

其他电脑请先保存文档，正常关闭PS，在新版后台安装／更新内置UXP44，再手动启动PS，确认后台实际加载0.3.44。只换EXE或只降低安装清单门槛不能生效。完整安装会同步本插件的共享加载登记，包括版本、名称和23.3.0的安装下限，保留其他登记。打开后台及安装后不自动启动PS。

204本机已构建并切换实际入口，PS24.0.1已正常重启加载UXP44。472项Python、双逻辑处理器／Below Normal的100项预览专项、21套脚本及冻结EXE启动／重启检查通过。本机三轮真实接口事务（低CPU确认、正常确认、低CPU取消）均等待两帧新值读回与app.refresh返回；同一目标、一次确认／一次撤销及取消恢复颜色／羽化／密度通过，资源恢复。原文档分层备份并恢复副本，源文件、配置和旧未知保留；真实后台在PS关闭时观察8秒未自动启动，手动启动一次成功。Win10 19045.3803／PS24.0.0 20221013.r.59／32GB故障机尚待复测，实体鼠标／Caps与画布目视未验；模拟版本分流不等于该机验收。无新增公开Release。

188／UXP43：核验原脚本真正退出，并等待原生解除确认后恢复PS点击、撤下小提示；内容未知时仍保留原记录并暂停插件写入。未退出时保护和阶段提示保持，实时预览、Esc恢复与一次撤销不变。[退出与结果核对](PREVIEW-EXECUTION.md)。

v0.4.165／UXP0.3.32已启用并按用户要求发布。本页区分实际PS事务与尚未完成的屏幕验收。

Adobe将[官方redrawDocument标为PS24.1起](https://developer.adobe.com/photoshop/uxp/2022/ps-reference/media/photoshopcore)，[矢量蒙版羽化与密度DOM为PS23.0起](https://developer.adobe.com/photoshop/uxp/ps_reference/classes/layer/)。这些API文档支持本次版本边界审计，不代表24.0.0已通过本项目实机验证。

## 使用与范围

菜单操作保持：长按Caps进入填充／描边或羽化／密度面板拖动；面板内松Caps确认，短按固定后再次Caps确认。回中心／空白、Esc或右键取消，恢复原值；确认后一次撤销可恢复原状态。颜色与蒙版仍为上下两个面板，间隙取消，普通填充不显示矢量蒙版控件。

PS23.3～23.x可通过安装准入检查，尚未实机验收，缺少预览能力时保留兼容草稿／确认提交。204起，24.0.0≤PS<24.1可在新UXP明确报告能力时走独立预览；24.0.0需UXP44，24.0.1已有路径保留。24.1+检查实际官方API；安装准入与各版本完整功能验收分别记录，24.0.0仍待对应实机验收。

无需Adobe账号、联网或额外安装工具。204对PS24.0.0的补充需同时更新主程序与内置UXP44，保存并正常关闭PS后安装，再手动启动，确认实际加载0.3.44；24.0.0继续加载43时不能启用此路径。

## 执行与取消

旧版不再从UXP模态事务内部调用JSX刷新。UXP先核验冻结目标和样式，保留当前工作请求，再由独立ExtendScript事务持续接收最新草稿。期间插件只进行本地文件通信，不进入另一个模态事务、不后台查询PS；一次原生执行覆盖整段预览和一份历史。

新值覆盖尚未处理的旧值，不把拖动积累成任务队列。每次写入前检查目标／选择／锁定和样式；写后核验颜色、蒙版值，结束时核验矢量路径、独立像素蒙版、父组和顺序。只改蒙版不重写填充／描边。羽化0–1000px、密度0–100%不缩减。

健康发布者持续续约，保持35秒后改值／确认已测；没有额外的两分钟固定截止。控制失联后，在原生调用下次可执行检查时取消并恢复；约4秒租约不是强制中断原生刷新的计时器。原生调用没有返回、回滚无法核对或终态存储失败时继续保留保护，只核对原请求，不重发、不切换通道、不自动重启或强杀PS。

原生终态先落盘，再由UXP持久化匹配收据；后台任务记录落盘后才解除busy。后续用户选择变化只更新当前选择反馈，不把已经核验的旧提交误判成需要重复执行。

## 已验证内容

本机PS24.0.1、UXP32、实际165入口：381项后台、40项前端、15份脚本检查（含55组预览事务模拟）及最终EXE启动／重启通过。独立原生引擎另有8项CPU受限事务通过。

完整UXP32通道15项真实预览事务通过，其中13项双逻辑处理器／Below Normal、2项正常资源：确认／一次撤销、取消、失联租约、1000px／0%边界、只改蒙版、独立像素蒙版、已有描边、已有渐变、20秒连续变化、35秒保持后再改值确认。每项核对匹配原终态，无新增未知请求；资源已恢复，用户原稿从核验备份重新打开。20秒样本中218次控制更新合并为17次实际写入，没有排队积压。

实际运行包中的原生组件另过四种主题、生产SHOWWINDOW及可见内容、输入／焦点／取消和编辑器路由自测；这不是实体Caps／鼠标验收。20秒事务验证结束后发生前台变化，保留了临时文档并停止清理；后续仅在已确认终态后正常清理，未强行抢回焦点继续原测试。

## 限制

旧版本机单次app.refresh等待约1.1秒，参数与绘制回执不代表实体帧率或按键到屏幕延迟；拖动显示频率取决于PS和文档成本，始终保留末值确认、取消和一次撤销。官方重绘接口的最低版本说明见[Adobe文档](https://developer.adobe.com/photoshop/uxp/2022/ps-reference/media/photoshopcore/#redrawdocument)。

自动界面工具仍报MXC CreateProcessSecurityEnvironment 0x80070020，实体菜单拖动与画布显示尚未验收；不能用数值读回或渲染自测替代。本轮按用户要求发布165，此项仍未验收。PS24.1+官方路径、本机以外i5／PS24.2、Win10／PS2024及真实集显／低内存仍待对应电脑测试。CPU并发限制不等同于这些硬件环境。

## 开发注意

本机旧ExtendScript对嵌套三元表达式的求值与现代JS不同，曾把纯色类型误选为渐变；当前采用明确分支。旧式像素／百分比单位使用正确的charID；羽化和密度分成同一历史事务内的两次属性写入，避免同一描述符静默漏写。RGB按8位编辑器精度核对，保留PS原始浮点值作诊断，不用整数完全相等误报。
