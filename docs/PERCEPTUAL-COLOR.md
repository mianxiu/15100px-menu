# 感知配色与渐变

去掉配色模式按钮与独立配色色块，所有配色圆点同时显示在感知色环里。主色点直径18逻辑单位、辅助点9单位；主色、两枚邻近色、互补色、两枚分裂互补色、两枚三色配色及强调色共九点联动。

色环直接显示全部九点，无需切换配色模式。主色点更大，作为整组配色的锚点；蓝色外圈标记当前应用的颜色点。悬停圆点查看其作用，点击将该颜色用于当前填充／描边或选中的渐变色标，拖动任一圆点时整组联动。右侧明度条调整主色的感知明度；RGB与Hex仍同排，Hex支持带#或不带#的六位输入及标准格式复制。

灰色、黑白色和高彩度颜色可能让多个色点落在同一位置。界面会轻微错开这些手柄，用细引线保留真实色位；颜色计算与配色关系不变。拾取手柄时保留鼠标偏移，点击不会把颜色突然跳到错开后的坐标。圆点布局在颜色或几何变化时更新，闲置时复用缓存；拖动色相仍复用色环网格缓存。

切换RGB／感知取色器、悬停提示不会写PS。点击其他颜色点或拖动改色会进入实时预览，此时其他图层操作暂时禁用，避免改变事务目标。面板内松Caps或固定后再次Caps确认，Esc／右键／中心或空白取消；颜色与羽化／密度共用一个事务，取消恢复全部原值、确认后一次撤销。

感知渐变沿用186：新建渐变、编辑色标颜色／位置默认采用感知插值。打开原渐变保留原插值，仅改羽化／密度不会重写渐变；右侧曲线图标可切换感知／线性／经典，明确选择后本次菜单保留。渐变条显示相应插值，PS原有角度、中间点、透明度、比例及描边属性保留；文档色彩配置和透明度会影响实际画布显示。
