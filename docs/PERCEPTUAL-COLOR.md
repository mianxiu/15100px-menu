# 方块取色、感知配色与渐变

188／UXP43：中央方块保留熟悉的RGB饱和度／亮度精细取色；外围圆角轨道显示色相和全部九种配色圆点。主色点更大；点击辅助点应用它的颜色，拖动任一点按OKLCH色相关系联动，主色明度与色度保持并映射到sRGB可显示范围。方块修改会建立新的主色锚点。圆点重合时沿轨道错开手柄并用引线标记真实色位，拾取不跳色；悬停查看配色作用。保留RGB取色器切换、RGB／Hex同排、内嵌复制、全图标、无标题和独立羽化面板。轨道颜色预热一次并缓存，闲置和按住不移动均不反复写PS。

保留主色、两枚邻近色、互补色、两枚分裂互补色、两枚三色配色及强调色共九点。方块是RGB取色方式，配色关系采用OKLCH／Oklab；不把两者混称为同一种算法。实际渐变仍采用PS感知插值，并保留原有经典／线性选项。颜色、羽化与密度共享实时预览、Esc取消恢复和一次撤销。仅切换通道、取色器、色标或复制Hex不写PS。

轨道几何、节点布局和代码独立实现，复用本项目图标与共享控件；未使用Coolorus的源码、图片、图标或界面素材。通用取色思路与具体界面表达需要区分，这不构成对任何具体产品的法律判断。
