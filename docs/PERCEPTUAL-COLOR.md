# 感知配色与渐变

新增OKLCH／Oklab感知配色色轮，拖动主色或配色圆点联动，提供邻近、互补、分裂互补、三色和强调色；右侧调整感知明度，下方色块点击应用。渐变条及PS实际渐变支持感知插值，保留实时预览、Esc取消恢复和一次撤销。

顶部第二排左侧切换RGB取色器／感知色轮，右侧选择配色关系。切换取色器或配色关系只改变本地显示，不写PS；拖动圆点或点击色块才更新当前纯色或选中的渐变色标。拖动任一配色点会旋转整组关系并调整彩度；RGB／Hex输入、黑白和颜色通道切换仍可使用。强调色同时调整感知明度，色域外颜色通过降低彩度映射回sRGB；配色关系不能代替具体背景下的文字对比度检查。

新建渐变、编辑渐变色标颜色／位置默认使用感知插值。打开已有渐变保留原插值；只改羽化／密度不会切换插值或重写渐变。渐变条右侧曲线图标循环切换感知／线性／经典，tip显示当前和下一方式；明确选择后，本次菜单里的颜色调整尊重这一选择。颜色条使用相应插值显示色标关系，PS保留原角度、中间点、透明度、比例与描边属性；文档色彩配置和透明度会影响实际画布显示，不能把颜色条当作画布像素取样。

确认／取消方式沿用原菜单：面板内松Caps或固定后再次Caps确认，Esc／右键／中心或空白取消。颜色与羽化／密度共享一次预览事务，取消恢复全部原值，确认后一次撤销。选择配色规则、通道／色标或复制Hex不会新增PS历史；输入框编辑时保留输入保护。RGB与Hex同排，Hex接受带#或不带#的六位值并自动转大写，复制为标准#RRGGBB。
