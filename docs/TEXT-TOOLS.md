# 文本工具

本机230／UXP0.3.59提供普通查找替换和文本拆分，公开下载仍225。

在PS单选文字图层，后台打开“文本工具”并“读取选中文字”。替换页输入查找与替换内容，检查预览及匹配数后确认；按字面匹配并区分大小写，换行可参与匹配。拆分页按换行拆分，或输入连续行号分组（例如1-3,4,5-7），检查预览后确认拆分并替换原层。确认会尝试激活PS；Windows拒绝激活则本次不执行，先点PS再重新确认。预览和取消不写PS。

拆分输出独立可编辑文字层，保持原父组、连续层序和字形位置，省略空白组但保留间距；确认合并为一次撤销。替换中未修改文字保留样式，插入文字沿用匹配起点样式，段落合并沿用新段落起点样式。样式、抗锯齿及方向均读回核验。目标、名称、文字或样式变化，以及预览超过60秒，需重新读取；未知结果保留原请求，不重发。

上限20,000 UTF-16单位、512KB样式、1,024段样式、查找200字符、替换500字符、拆分64组。缺失字体、手动字距、空结果或超限拒绝。拆分暂不支持路径／弯曲文字、剪贴、图层效果、多栏／多行／竖排段落及溢出文本；不会静默简化。正则只完成离线评估，当前未启用任意正则。

529后端、31组Node、45前端、构建及实际EXE／原生组件核验通过。真实PS24.0.1低CPU／正常基础、样式、过期拒绝、隐藏层、超限、中文长替换、64组及一次撤销通过；真实服务无头浏览器验证三宽度、本地预览取消零写入、确认一次及PS独立读回。低CPU64组实际浏览器确认至返回55.271秒，属于接口完成阶段，无可比旧版完成时间，不声称提速。点文字72／300dpi、旋转与段落／自动换行72dpi已有零像素差样本；BMP诊断按历史状态恢复，实际一次撤销另由核心批次验证。

300dpi自动换行段落已在230实际入口补齐低CPU／正常零像素差与历史状态恢复检查；实体键鼠、原24.2及其他宿主待验。原64组45秒超时依据原请求匹配终态核对成功并撤销收尾，历史未知时间线保留；现拆分执行等待120秒、客户端175秒，其他命令期限不变。原稿／配置／CPU与旧未知保留，自建临时文档已收尾，无当前pending。接口与无头浏览器不代替实体输入验收。

## 正则评估（2026-10-21）

本轮结论：暂不在浏览器或UXP事件线程直接执行任意用户正则。普通查找仍按字面匹配，不把输入偷偷当正则。

隔离Node测试仅使用自建字符串，不连接PS或读取用户文字。`/^(a+)+$/` 匹配30个`a`加一个`!`，500ms期限内未完成；同一事件线程的10ms定时器也没有执行。外部进程在536.618ms收回该自建计算子进程，PS进程和资源未改变。简单正则和字面查找能完成，但不能据此推断任意表达式有界。原始证据：`.runtime/regex229-assessment.json`，可重复工具：`tools/assess-text-regex.py`（输出`.runtime/text-regex-assessment.json`）。这是Node引擎离线诊断，不是UXP、浏览器或PS24.2实测，也不是功能提速对照。

ECMAScript规范定义了匹配继续与重复匹配的回溯行为，嵌套量词可能反复尝试不同匹配路径。[ECMAScript规范](https://tc39.es/ecma262/2024/multipage/text-processing.html#sec-repeatmatcher)。模态作用域内应等待已发出的PS操作真实返回，并保留取消处理；不能靠另起定时器放弃宿主写入或解除busy。[Adobe模态说明](https://developer.adobe.com/photoshop/uxp/2022/ps-reference/media/executeasmodal)。

若后续要求启用正则，计算必须先在PS之外、可独立终止的计算进程完成。确认语法、替换转义、零宽匹配、Unicode／UTF-16区间、重叠、输出和匹配数量上限后，再将明确的编辑区间送入现有单历史事务，写前重新核验原文字及样式；超时不提交PS操作。不得在PS模态中试跑正则，也不得因计算超时重发未知宿主请求。
