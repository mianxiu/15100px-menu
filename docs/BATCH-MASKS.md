# 多图层批量羽化／密度

## 171：原生动作批次加速

v0.4.171／UXP0.3.36 在旧版独立执行端为 8–128 层蒙版预览使用有界原生动作批次：每批最多16层、32条单属性命令。少于8层保留直接写入；现代 UXP 分支仍使用原有 batchPlay。已经加载UXP36时只更新主程序，无需重装插件或重启PS。

每条命令绑定文档ID和图层ID，只包含发生变化的羽化或密度。每批动作加载后、执行前重新检查活动文档、完整选择和受影响图层及祖先锁定；每帧写前、写后、重绘后和最终完整核验均保留。将逐条脚本调用交给原生动作批次执行，减少分派及中间刷新开销；没有省略内容／路径／独立像素蒙版／顺序校验，没有降低预览刷新频率，也没有改变选择来换速度。

临时动作使用请求专属名称，无快捷键；每批完成后删除，不修改用户动作播放设置。批次间读取经过请求／会话／凭据校验的取消信号；半帧不会发布已完成预览确认，退出同一个历史事务后恢复各层原值和选择并完整读回。确认仍只有一次撤销。加载／执行／清理异常不重放；无法确认动作清理或回滚时保留未知保护。

### 验证与限制

实际入口171／UXP36；398后台／原生回归、18份脚本套件、冻结EXE启动／重启检查通过。8项最终真实PS事务（低CPU7、正常1）覆盖2／7／8／32／128层、只改密度、跨组、渐变和独立像素蒙版、每次确认前两次读回重绘、一次原生撤销及取消恢复；另1项64层写入批次中取消，验证半帧未确认且原值／历史恢复。6项批量事务和中途取消均检查动作面板不变、临时动作文件清理。4项目标保护检查通过，配置、用户文档、资源和历史未知记录保留。

候选128层和最终入口一次7层测试因前台变化安全取消且原值读回一致，恢复后在新临时文档完成验收；另一次在提交修改前因同步原生读取后UXP心跳暂时过期而停止，测试工具现等待心跳恢复。首次并行回归有一项菜单时序失败，结束PS测试后整套398项通过；失败日志保留。实体Caps／鼠标观感、现代PS及故障i5／PS24.2、Win10／PS2024仍待对应实机验收，不宣称全版本提速。

后续重点是首次准备的属性读取和完整核验效率；不能以旧快照、降低刷新或删除校验替代这些工作。

## 170：低配批量预览读取优化

v0.4.170 沿用 UXP 0.3.36，优化旧版独立执行端的批量蒙版核验；现代重绘分支和单层颜色预览保持原实现。已加载 UXP36 的电脑只需更新主程序，无需为本次改动重装插件或重启 PS。

首次仍完整比对 UXP 冻结目标和内容。后续每次核验重新读取完整原生路径及填充／描边／独立像素蒙版属性，使用保留类型、单位、嵌套值和字段存在性的原生字节精确比较，减少反复拆解、排序和编码。每次写入前仍读取最新选择；原生快照不同则从同一次读取逐项校验 ID 集合。只在一次同步读取内部复用父组、图层 ID 和集合长度，不跨帧沿用旧宿主数据，不用有碰撞风险的摘要代替内容比较。

写前、写后、重绘后及最终核验均保留。实时预览、最新值合并、取消恢复各层原值与选择、确认一次撤销、真实阶段进度和未知结果不重发保持。尝试合并同一层两项写入的原型未通过旧版 PS 核验，已回滚弃用；正式版继续分别写入属性。

## 操作

在图层面板选择 2–128 个带矢量蒙版的未锁定图层，按 Caps 打开图层菜单。左侧显示独立的“羽化／密度 · N 个图层”面板；多选时不显示单层填充／描边编辑器。

- 羽化范围 0–1000 px，密度范围 0–100%。
- 各层原值不同，滑条显示“混合”。拖动后将该项统一设为所选值；未调整的另一项保留每层原值。
- 拖动使用一个实时预览请求，合并中间更新；不为每层分别打开事务或刷新画布。
- 面板内松 Caps 确认；短按固定后再次 Caps 确认。一次撤销恢复整批。
- Esc、右键、中心或空白松键取消，恢复每层各自原值。只打开面板而未调整不写入 PS。

## 范围与保护

目标必须全部具有可读取的矢量蒙版，且图层及祖先组未锁定。含不支持的图层或超过 128 层时，整批编辑不提供，不静默跳过部分目标。独立像素蒙版不属于这两条滑条的编辑范围。

保持选中集合、活动图层、各层父组及顺序，核对矢量路径、填充／描边和独立像素蒙版属性。写入前后重新核验；选择或内容变化时拒绝／回滚，不沿用旧目标。路径快照过大时停止提供批量编辑，需减少选择数量。

沿用现有按宿主能力分流的现代重绘／旧版独立执行端。批量功能要求实际加载 UXP 0.3.35；旧插件在请求发布前拒绝。忙碌时不排队，未知结果只核对原请求，不重发、不切换执行端补做。

## 验证与性能边界

394 项后台／原生回归、16 份插件脚本（批量事务 28 组）、最终 EXE 启动／重启、四主题面板渲染及输入／锁定／画布分流／取消自测通过。现代重绘分支有模拟覆盖，尚未在现代 PS 实机验证。

本机 PS 24.0.1 完成 8 项批量预览事务和 3 项单层回归，其中 9 项双逻辑处理器／Below Normal，2 项正常资源。批量覆盖 2、8、32、128 层，跨组、只改一项、两项修改、提交前两次读回／重绘、一次原生撤销和取消恢复；另有 4 项旧状态／锁定／不支持图层／恢复可用性检查。原生读取独立核对内容、路径、顺序、所选集合和活动图层。

取消测试发现 PS 恢复历史时会还原成旧单选，现已在回滚后重建原多选和活动图层，并在刷新后再次核验。首次失败收据及原记录原样保留，未改成成功；修复后另建临时文档验收通过。

同一帧内仅扫描一次各父组的兄弟顺序；写入时检查当前目标及其祖先锁定，避免每写一层再扫描整批锁定。跨帧仍重新读取，不删减写入前后核验，不增加操作队列。

**大批量在旧版 PS 上仍有明显延迟。** 本机双核限制下，32 层首次预览读回和重绘约 6.4 秒，第二次约 3.2 秒；128 层首次约 28.4 秒，第二次约 14.3 秒。这是单次短测的宿主事务数据，不是鼠标到画面的延迟，也不是平均或全机型承诺。大选择下合并中间值，最终值仍需等待整批处理；需要更快反馈时可减少每批数量。

CPU 限制仅模拟并发受限，不等于真实 i5／低内存／集显。故障 i5／PS24.2、Win10／PS2024、现代重绘接口及实体 Caps／鼠标观感仍需对应实机验证。资源限制及用户文档已恢复；本轮无新增未结束请求，早期失败／未知记录保留。
