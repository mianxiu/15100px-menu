# 多图层批量羽化／密度

## 181：新鲜原生树减少首次预览读取

181／UXP40优化旧版独立预览的图层读取：8–128层在每次同步校验内使用新鲜原生图层树、描述符及祖先锁定读取，减少重复DOM访问；小批和超出原生树范围的文档保留原路径。PS24.0.1双逻辑处理器／Below Normal同会话样本，128层首次预览完成读回及重绘12.13→6.02秒，后续帧10.77→6.20秒。保持完整新鲜校验、实时预览、Esc取消恢复、一次撤销及收尾点击保护。428回归、19脚本套件、7项真实PS事务（低CPU6／正常1）、4项外部修改和4项选择保护通过。已加载UXP40时只更新主程序，无需重装插件或重启PS；初次菜单完整取样和跨硬件／现代PS视觉仍待优化及对应验收。

### 怎么使用

多选2–128个未锁定且带矢量蒙版的图层，在羽化／密度面板拖动预览；松Caps或固定后再次Caps确认，整次调整只有一次撤销。菜单尚未确认时按Esc取消，恢复各层原值；取消后再松Caps不会转为确认。颜色／描边与羽化面板原有共同事务不变，已经确认完成的修改使用Ctrl+Z。关闭后仍在确认／恢复时，小转圈与真实阶段保持到原请求确定结束和点击保护解除。

### 读取方式和保护

旧版独立执行端在一次同步校验内完整扫描当前原生图层树，核验图层ID、索引、组结束标记、父组及兄弟顺序。选择成员及祖先锁定来自本次描述符，同一次校验内共享祖先和描述符，下一次校验重新读。每批动作加载后、执行前再次新鲜读取所涉及图层及祖先锁定；没有跨帧使用旧树或旧锁定批准写入。

首次仍逐层与UXP期望快照比对颜色／描边、矢量路径、独立像素蒙版、顺序、精确双精度羽化及原生密度刻度。写前、写后、重绘后及最终完整核验均保留，没有降低刷新频率、扩大误差、排队补写或重发未知请求。PS报告的原生结构计数达到4096或以上时保留原DOM路径；不完整、索引／组结构不一致或锁定读取失败时停止。现代UXP重绘分支和单层颜色执行器未修改。

## 171：原生动作批次加速

v0.4.171／UXP0.3.36 在旧版独立执行端为 8–128 层蒙版预览使用有界原生动作批次：每批最多16层、32条单属性命令。少于8层保留直接写入；现代 UXP 分支仍使用原有 batchPlay。已经加载UXP36时只更新主程序，无需重装插件或重启PS。

## 操作

在图层面板选择 2–128 个带矢量蒙版的未锁定图层，按 Caps 打开图层菜单。左侧显示独立的“羽化／密度 · N 个图层”面板；多选时不显示单层填充／描边编辑器。

- 羽化范围 0–1000 px，密度范围 0–100%。
- 各层原值不同，滑条显示“混合”。拖动后将该项统一设为所选值；未调整的另一项保留每层原值。
- 拖动使用一个实时预览请求，合并中间更新；不为每层分别打开事务或刷新画布。
- 面板内松 Caps 确认；短按固定后再次 Caps 确认。一次撤销恢复整批。
- Esc、右键、中心或空白松键取消，恢复每层各自原值。只打开面板而未调整不写入 PS。

## 范围与保护

目标必须全部具有可读取的矢量蒙版，且图层及祖先组未锁定。含不支持的图层或超过 128 层时，整批编辑不提供，不静默跳过部分目标。独立像素蒙版不属于这两条滑条的编辑范围。

保持选中集合、活动图层、各层父组及顺序，核对矢量路径、填充／描边和独立像素蒙版属性。写入前后重新核验；选择或内容变化时拒绝／回滚，不沿用旧目标。路径快照过大时停止提供批量编辑，需减少选择数量。

沿用现有按宿主能力分流的现代重绘／旧版独立执行端。批量功能要求实际加载 UXP 0.3.35；旧插件在请求发布前拒绝。忙碌时不排队，未知结果只核对原请求，不重发、不切换执行端补做。
