# 读取策略实验夹具（不随应用发行）

这是本机PS24.0.1测试过的临时UXP0.3.11实验实现，不是生产插件升级。生产继续使用`uxp/offline-probe`中的0.3.10。`main.js`与`labels.js`保留实际受测代码，不能根据实验名称把它误装成默认执行端。

所有创建仍经过实时目标／能力校验、同一可撤销历史事务、原生插入位置与原层核验、接受及最终结果持久化。实验只切换类型／背景／锁定元数据的读取方法，以及闲置刷新策略；文档模式／位深、ID与拓扑读取共同保留。没有任意脚本／描述符入口，不重发未知操作，也不回退COM。

固定`inspect`诊断参数：`read_probe`读取三个方法的当前快照；`refresh_probe`读取计数；`read_experiment`只允许`dom/get/multiget`与`poll/events`、指定活动文档ID、可选`objects/strings`通知格式。策略仅适用于标题以`Read strategy benchmark scratch`开头且ID匹配的临时文档，90秒自动失效；传入`null`清除，重启默认DOM／轮询。`read_probe`本身只读。

夹具只含三份无凭据源码。通过后台管理导入这三份文件组成的ZIP，再正常关闭PS、安装及重载；勿复制实际`probe-config.js`或用户配置。测试前正常退出空闲菜单服务，避免原生热键与测试共享请求槽。测试后在PS关闭时使用后台回退，直到内置0.3.10匹配，再正常启动PS并核验实际状态。报告与复现脚本见[读取策略实测](../../../docs/READ-STRATEGIES.md)。
