## EXE 版本

`dist/PhotoshopMenu.exe` 是 Windows x64 单文件应用，已内置 Python 后台、C++ Dear ImGui 菜单、原生热键、管理网页、图标及UXP0.3.18；旧JSX仅作兼容资源保留。使用时无需安装 Python 或 Node.js，也无需复制源码文件夹。

双击 EXE 后默认驻留托盘；双击托盘打开后台管理。在有效Photoshop工作区前台、未编辑输入框且鼠标位于工作区时，单独短按Caps松开固定菜单，长按220ms或移动鼠标12物理像素展开；快速Caps组合直接执行。同版本再次启动会复用已有服务并打开管理窗口；v0.4.6 起，版本不同则明确报错，不复用旧服务。通过托盘或管理页的“退出服务”退出。

应用升级流程：等待图层操作完成 → 从托盘或管理页退出服务 → 等待菜单、热键和主进程退出 → 替换统一入口 `dist/PhotoshopMenu.exe` 及其 SHA256 文件 → 重新打开该 EXE。管理页“当前运行版本”显示实际服务版本与程序路径。构建时旧 EXE 仍被占用，可先用 `./build-exe.ps1 -OutputDirectory .runtime/release-candidate` 暂存，完成退出后再复制到统一入口；暂存构建成功不代表运行版本已切换。设置和脚本包保留在原数据目录。

设置、插件管理／回退数据、日志与管理窗口配置默认保存在 `%LOCALAPPDATA%\PhotoshopMenu`（以后台实际应用数据目录为准，Windows可能重定向），不会写入 EXE 的临时解压目录；替换 EXE 可保留这些数据。开发版仍使用项目 `.runtime`。可用 `--data-dir` 指定其他数据目录：

```powershell
.\dist\PhotoshopMenu.exe --headless
.\dist\PhotoshopMenu.exe --port 15152 --data-dir D:\PhotoshopMenuData
```

管理窗口使用系统 Edge，找不到 Edge 时使用默认浏览器。菜单写入使用本地UXP；最低PS24.0.1，COM用于启动／兼容读取，不作为UXP失败后的自动写入回退。`dist/PhotoshopMenu.exe.sha256` 提供构建文件校验值。

## Photoshop 操作菜单

先启动 Photoshop 并打开文档，使其主窗口处于前台，把鼠标放在画布或图层面板上，再按 CapsLock 唤出对应环绕菜单。短按≤220ms松开后固定，点击选项执行，Esc取消；固定后的普通菜单可再次Caps关闭，颜色草稿则再次Caps提交一次；长按>220ms向可用方向滑动高亮选项，松开执行，颜色需要选中具体色块。中心、对角空隙、不可用方向、超出选择范围或窗口外均取消；滑过选项后回到中心也会取消。靠近屏幕边缘时菜单会整体避让，原始按下位置仍保留取消区，避免原地松开误执行。Photoshop 右键菜单保持原样。

| 默认快捷键 | 动作 |
| --- | --- |
| CapsLock | 单独短按松开固定；长按220ms或物理鼠标移动12px展开，命中松键单次执行，中心／空白取消 |
| CapsLock+A | 选择组内／相邻图层，按当前目标可用性执行 |
| CapsLock+C／V | 复制／粘贴图层样式 |
| CapsLock+F | 打开PS原生图层样式窗口；窗口结束前任务保持忙碌 |
| CapsLock+W／S | 单选上一个／下一个图层，多选时从冻结的活动层定位 |
| Shift+CapsLock+W／S | 保留已有选择，从选区边缘向上／下追加 |
| F5 | 转换当前选择为智能对象；单个已有智能对象保持不变 |
| Esc | 收起菜单，未提交草稿取消 |

图层菜单上方为「置顶／置底／上移／下移」四段图标加文字；底部c／v／f／w／s按同名动作执行，Shift+w／s追加多选。Ctrl+Caps+W／S及菜单内Ctrl+W／S移动绑定已移除，上移／下移只从上方按钮操作。颜色标签通过具体色块选择，不再使用Caps+C标橙色。F5多选转换须满足同父组等执行条件；仅接管默认单键，Shift+F5等组合保留PS原行为；后台自定义或禁用设置以保存值为准。

首页保持2列×4行最近预设，图像剪贴板单独位于上方；预设点击直接新建，中心松键取消。图层菜单的RGB8／16位单选未锁定形状／填充目标可编辑本地颜色草稿，Tab切换纯色／渐变／图案；渐变使用连续颜色条和可拖动色标，松Caps在面板内单次提交，固定后再次Caps提交，中心／空白、Esc及右键取消。画布／通用菜单不显示图层排序和颜色编辑器。

菜单中的按钮调用后台的同一组动作。成功执行后自动收起；左键或中键点击菜单外部取消，并消费这一组按下/抬起，避免误点 PSD。右键取消菜单时消费该次点击，菜单持有焦点时恢复到PS；菜单未显示时保留PS原生右键。切换其他应用时不会截获该应用的点击或抢回焦点。

Caps前缀意图在输出线程处理：快速组合键不发菜单唤出消息，也不增加220ms执行等待；单独Caps按既定短按／长按规则显示，重复按键不重复执行。菜单已展开后按组合键会先取消菜单，再提交一次命令。Tab／Caps+Tab仅做过隔离测试，尚未启用新映射；实体Caps／F5、输入与不同PS权限环境仍需复测。

- 新唤出必须满足 PS 主窗口前台和鼠标在窗口内，接口或托盘也不能绕过。
- 菜单取得焦点后允许继续交互；隐藏菜单会尝试恢复 PS 焦点。
- 切换其他应用，或 PS 最小化、关闭后，菜单自动收起。
- 显示位置限制在 PS 窗口与显示器工作区的交集内，按 DPI 缩放。
- 管理页面始终独立，不需要 PS 焦点；图层操作则需 PS 或由它唤出的原生菜单取得焦点。
- 可配置菜单尺寸、菜单唤出/收起快捷键、启用开关。图层动作快捷键位于后台快捷键设置；下拉选键尚未实现。保存后立即生效，并在重启后保留。

菜单任务通过UXP本机文件协议执行，忙碌时拒绝新交互请求，不排队。执行前重新核对会话／文档／活动层／选择及能力；改变选择后先同步快照再确认完成。超时或断线只核对原请求终态，不重发、不回退COM，不通过重启清除未知结果。升级或回退期间禁止并发图层操作。

### 历史JSX脚本包管理

以下仅解释保留的JSX兼容包格式，不是当前菜单执行端或当前UXP插件管理。
